Add the shape library and `useM3Morph` to `@vkieu/mui/primitives`: a TypeScript port of `androidx.graphics.shapes` (`RoundedPolygon`, `CornerRounding`, feature-matched `Morph`) with Compose's 35 Material 3 Expressive `MaterialShapes`, SVG path helpers (`polygonToPath`, `morphToPath`, `morphPathAt`), and `useM3Morph`, which turns a shape sequence and a Motion progress value into an animated SVG path.
