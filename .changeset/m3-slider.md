Add `Slider` and `RangeSlider`: M3 Expressive sliders in sizes XS–XL, horizontal or vertical, continuous or discrete with stop indicators, centred, with inset icons (medium and up) and an optional value indicator. The track follows Compose's drawing (thumb gaps, inside corners, stop indicators and tick colours) as CSS, so it renders correctly on the server and nothing is positioned. Arrow keys, Page Up / Down and Home / End adjust it, mirrored in RTL.
